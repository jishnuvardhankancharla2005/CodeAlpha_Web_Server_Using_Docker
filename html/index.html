Advanced Production Commands

Scale Replicas docker compose up -d --scale webserver=5

Horizontally scales web server cluster to 5 backend container replicas on demand.

Resource Stats docker stats --format "table {{.Name}}\t{{.CPUPerc}}\t{{.MemUsage}}"

Monitors live CPU & Memory resource usage against defined 256MB container limits.

Crash Simulation docker exec -it <container_id> kill 1

Simulates PID 1 crash; tests Docker restart policies and Nginx load balancer failover.

Network Isolation docker network inspect codealpha_backend-net

Inspects isolated bridge network routing between web replicas and Redis database.
